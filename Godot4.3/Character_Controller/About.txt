This is the resources needed for a character controller that also can interact.

The animation need to either have left, right, back, and default animation key or
on_direction_change() need to be overriden to support a diffrent animation key set.
Also the node need to have a AnimatedSprite2D and asign it as the animation.

Interaction need a RayCast2D node to be assign to it. 

How Interaction works: Something need to call interact(). The logic is not inclued since
it varies too much and I have a controller handler that handles listen to input.

When called, it will look for a body or area that inherit Interaction_Component_2D
and call the interact() on it. The owner of this area or body should be listening to
the interaction so it can perform an action. 

If the owner of the area or body do not need to perform logic, then no worries since
the character2D interact will return true if there was an interaction and false if not.
Overriding the Interaction_Component_2D interact logic can allow more controll if needed.
